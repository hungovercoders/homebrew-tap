# hungovercoders Homebrew tap

Homebrew casks for the hungovercoders tools, written by each project's
release workflow. Nothing here is edited by hand.

```sh
brew install hungovercoders/tap/apic
```

| Cask | What it installs | Project |
|---|---|---|
| `apic` | `apic`, its man pages and shell completions, on macOS and Linux | [hungovercoders/apic](https://github.com/hungovercoders/apic) |

`brew upgrade apic` follows releases. To check a download before trusting
it, every release is signed and ships a software bill of materials; see
[verifying a release](https://apic.sh/verifying/).

## How it is maintained

`Casks/<name>.rb` is generated by [goreleaser](https://goreleaser.com) from
the project's `.goreleaser.yaml` (`homebrew_casks:`) on each tagged
release, and pushed here with a token that can write to this repository
only. A fix to a cask goes in the project's goreleaser config, not here.
